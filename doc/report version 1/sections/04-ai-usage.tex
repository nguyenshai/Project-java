\section{AI usage declaration}
\label{sec:ai-usage}

The team used AI tools as assistants in Version 1. The assignment sets no policy
on AI use~\cite{ref:assignment}; the team declares it here so the grader can see
which parts were assisted and how they were checked. Every result in this report
and in the submission was reviewed, tested and accepted by the members, who are
responsible for it and can explain it.

\subsection{How AI output was checked}

\begin{itemize}
  \item \textbf{Code:} every change is compiled and checked with the automated
    tests (\texttt{mvnw verify}) and by running both Swing applications.
  \item \textbf{Database:} the creation script and the sample data are run twice
    on a clean PostgreSQL 17 database; deliberately invalid inserts must be
    rejected, and the sample encrypted messages and password hashes are verified.
  \item \textbf{Report:} each section is checked against the assignment and
    against the running applications, and every figure is a real screenshot.
  \item \textbf{Acceptance:} as for all work, a task assisted by AI is recorded
    as done only after both members have reviewed and accepted it
    (Section~\ref{subsec:task-results}).
\end{itemize}
